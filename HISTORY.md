# Public development history

This repository was published from the maintained Corio ECG project on
15 October 2026. Its creation date is the public release date, not the start
of the project's development.

The import retains all 158 commits reachable from the original main branch at
`df61eb39d42238b9213e9cc0e27bbbac62de9364`, including the original commit dates,
author names, messages, and parent relationships. It is not a new single-commit
snapshot and is not a claim of 158 community contributions.

Before publication, every historical tree was restricted to source code,
scripts, tests, configuration files, the compatibility patch, and environment
templates. Record-level research outputs, private development notes, and the
separate website were excluded throughout the history. Commits that changed only
excluded files remain as empty historical records rather than being discarded.
There are 117 commits that change retained public files and 41 such empty
historical records; the later publication commit is additional.

The maintainer's private author/committer email was replaced with the GitHub
noreply address. Tree and email changes necessarily produce new commit hashes.
The original private repository and its additional development branches remain
unchanged. PR discussions, issues, and private branch tips are not imported.

A separate publication commit adds licensing, third-party notices, contribution
guidance, and the public README. It also pins Open-ECG-Digitizer to the immediately
following upstream revision that introduces its license without changing its
executable Python source. These are release-preparation changes made on the
publication date; they are not backdated.

The project is early-stage. Public release and retained maintenance history do
not demonstrate broad adoption, clinical validation, or regulatory approval.
